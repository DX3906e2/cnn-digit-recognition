## 一、项目概述

- **目标**：从零实现"输入图片 → 灰度化 → 高斯卷积去噪 → CNN 识别数字 0-9"的完整程序。
- **定位**：简化版工程交付，强调**原理透明**与**全流程可视化**（每一步都真实可看）。
- **技术路线**：Python + NumPy **全手写**（不借助深度学习框架），本地 CPU 训练。
- **交付形态**：CLI 训练/评测脚本 + Tkinter 可视化窗口（逐步展示三阶段）。

## 四、硬约束（违反即返工）

1. **全手写**：高斯核生成、二维卷积、CNN 前向/反向传播、梯度下降，一律手写 NumPy。
   禁止用 scipy / torch / opencv / sklearn 的卷积、滤波、神经网络封装代替。
   （**数据加载同样手写**：urllib 下载 IDX 原始文件 + numpy 解析，**不使用 sklearn**；matplotlib 仅用于画图。此口径以保证 `requirements.txt` 只含 numpy、matplotlib 为前提。）
2. **去噪必须真实**：图片真实经历 灰度化 →（训练时）加噪 → 高斯核卷积去噪，不许装饰性跳过。
3. **目录分离**：`src/` 只放代码实现；一切 agent 思考痕迹放 `agent/`；`.gitignore` 强制排除 `agent/` 与权重文件。
4. **不建五段链路目录**（无 0-5 目录）。
5. **第三方参考只读**：`third_party/` 下的克隆仓库（LeNet / CNN 参考实现）仅用于阅读对照与梯度检查参照，**禁止整段复制进 `src/`**。

## 五、系统架构（模块与职责）

| 模块 | 文件 | 职责 |
|------|------|------|
| 配置 | `src/config.py` | 集中存放全部超参与路径，被 train / evaluate / app 共用 |
| 滤波器 | `src/filters.py` | 高斯核生成、二维卷积（前向 + 反向） |
| 数据 | `src/data.py` | 手写 IDX 下载/解析（urllib + numpy）、灰度化/归一化、高斯噪声注入 |
| 网络层 | `src/layers.py` | Conv / ReLU / MaxPool / Flatten / FC / Softmax 的前向与反向 |
| 网络 + 损失 | `src/cnn.py` | 组装层为 CNN；含 forward / backward / params / 梯度检查 / 交叉熵损失及其梯度 |
| 训练 + 优化 | `src/train.py` | CLI：训练循环（含 SGD 权重更新）、保存权重、输出训练曲线 |
| 评测 | `src/evaluate.py` | CLI：测试集准确率、混淆矩阵 |
| 可视化窗口 | `src/app.py` | Tkinter + 嵌入 matplotlib，三阶段逐步展示 |
| 绘图工具 | `src/viz.py` | 三联图/特征图/核热图等复用绘图函数 |

**关键接口（建议签名，实现可微调）**

```python
# filters.py
gaussian_kernel(k: int, sigma: float) -> np.ndarray          # (k, k)，和为 1
convolve2d(image: np.ndarray, kernel: np.ndarray) -> np.ndarray
convolve2d_backward(dout, x, kernel) -> (dx, dkernel)        # 供卷积层反向使用

# data.py
load_mnist() -> (X_train, y_train, X_test, y_test)           # 归一化到 0~1
add_gaussian_noise(X, sigma) -> X_noisy

# cnn.py
CNN.forward(x) -> probs
CNN.backward(dprobs) -> grads
CNN.params -> list[np.ndarray]
gradient_check(x, y, eps) -> max_rel_error                   # 数值梯度 vs 解析梯度

# train.py
fit(model, X, y, cfg) -> history                             # 返回 loss/acc 曲线

# evaluate.py
accuracy(model, X, y) -> float
```

## 六、数据流（管线）

```
输入图片
  → 灰度化（RGB 取加权和 / 已是灰度则跳过）
  → 归一化到 0~1
  → [训练与测试时] 注入高斯噪声（sigma 可配）
  → 高斯核真实二维卷积去噪
  → CNN：Conv → ReLU → Pool → Conv → ReLU → Pool → Flatten → FC → Softmax
  → 输出 0-9 的概率，取最大者为识别结果
```

## 十一、验收标准（Definition of Done）

- [ ] 手写卷积结果与朴素实现一致（误差 <1e-6）
- [ ] 梯度检查通过（数值梯度 vs 解析梯度，误差 <1e-6 量级）
- [ ] 测试集准确率 ≥ 97%（无噪训练）；含噪条件下合理（不低于 90%）
- [ ] 窗口能载入本地图片，并分阶段展示：灰度化 → 加噪/去噪 → 识别结果与特征图
- [ ] `agent/` 未被提交进版本库
- [ ] 全流程可由 CLI 脚本复现，且输出真实指标

## 十二、风险与对策

| 风险 | 对策 |
|------|------|
| 手写反向传播写错不报错（最陡） | 先做梯度检查 + 小样本冒烟，逐层定位 |
| 高斯去噪使边缘变模糊 | 属线性平滑固有代价；可调核大小/sigma 权衡 |
| 高斯去噪对椒盐噪声无效 | 注噪与去噪已配对为高斯型，勿混用 |
| Python 3.9 + numpy 2.0 兼容小坑 | 遇报错查 numpy 2.0 迁移说明 |
| 无 GPU | 本项目规模小，CPU 足够 |
| MNIST 原站（yann.lecun.com）偶发不可用 | 下载函数内置镜像兜底：`storage.googleapis.com/cvdf-datasets/mnist/` 或 `ossci-datasets.s3.amazonaws.com/mnist/` |
